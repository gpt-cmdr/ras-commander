## Delivered contract

`RasTerrain.export_rasmapper_terrain(...)` selects one registered terrain by
project/name and returns a bool-compatible `TerrainExportResult`. It exports one
nearest-neighbor Float32 GeoTIFF at exact source-derived 1x/2x/4x/8x resolution,
optionally applies native vector modifications, snaps requested bounds to an
authoritative source grid, validates raster semantics, atomically promotes the
output, and writes a JSON receipt.

The helper loads the exact `.rasmap` terrain XML, including registered source
order, priorities, masks, stitches, and modifications. An owned out-of-process
helper invokes the private HEC-RAS `TerrainLayer.GenerateNewRasTerrain`
contract verified in 6.4.1 through the locally installed 7.0.1 runtime. It does
not use Controller COM, drive a dialog, register the derivative, or reproduce
terrain-modification mathematics.

Qualified exact releases are HEC-RAS 6.4.1, 6.5, 6.6, and 7.0.1. Exact 7.1 is
forward-open so its future official installation can run without another
allow-list change; the helper retains its exact runtime contract check. The API checks an
explicitly supplied `RasPrj.ras_version` and its identifiable executable
release before output or native work, and it requires an explicit version to
match that exact release. HEC-RAS 6.3.x lacks the bounded contract; 6.4.0 has
an official terrain-elevation defect; 6.7 is beta-only; 7.0.0 has an official
terrain-modification export defect. There is not yet a published HEC-RAS Classic
7.1 release, so 7.1 carries no qualification claim. Unsupported terms fail closed
with version-specific guidance.
