# AORC workflow references

- [Precipitation contract](https://github.com/gpt-cmdr/ras-commander/blob/main/ras_commander/precip/AGENTS.md) provides method selection, optional dependencies and validation context. Read its AORC section when choosing retrieval/processing; inspect installed source docstrings for exact parameters.
- [Notebook 900](https://github.com/gpt-cmdr/ras-commander/blob/main/examples/900_aorc_precipitation.ipynb) derives model bounds with `HdfProject`, builds a storm catalog with `PrecipAorc.get_storm_catalog`, downloads selected rainfall using `PrecipAorc.download`, and later creates storm plans. Source-only requests stop before plan creation. Reuse coverage, time-window and rainfall checks; keep the notebook's event thresholds and buffer choices identifiable as fixture settings.
- [PrecipAorc source](https://github.com/gpt-cmdr/ras-commander/blob/main/ras_commander/precip/PrecipAorc.py) describes AWS Zarr subsetting and NetCDF output, reprojection and optional dependencies. Inspect current source or installed help when requested store/product availability differs; a notebook does not establish current remote coverage.

For historical callers requesting design storms under this compatibility name, route to `ras-gridded-precipitation`. [Notebook 720](https://github.com/gpt-cmdr/ras-commander/blob/main/examples/720_atlas14_aep_events.ipynb) demonstrates one-project Atlas 14 suites; [notebook 722](https://github.com/gpt-cmdr/ras-commander/blob/main/examples/722_atlas14_multi_project.ipynb) extends those to multiple projects. They are conditional design-workflow references, not AORC prerequisites. Select temporal distributions and areal-reduction assumptions from the task and relevant [HEC planning references](https://github.com/gpt-cmdr/ras-commander/blob/main/docs/development/hec-planning-references.md); do not copy blanket regional distributions or area-to-factor rules.
