Its current native route rejects true multipart and interior-ring authoring; a one-member hole-free MultiPolygon is normalized. Inspect the installed contract before accepting topology; do not silently flatten it.
- [Infiltration base/region authoring](https://github.com/gpt-cmdr/ras-commander/blob/main/examples/218_infiltration_base_override_authoring.ipynb) creates the geometry's native override schema, writes geometry-wide Base Overrides and one named region as distinct tables, confirms neither mutation overwrites the other, recomputes, and compares final plan arrays by cell ID. Fully contained cells establish region attribution; disjoint cells establish base attribution. Boundary intersections and hydraulically inactive regions need separate interpretation.
- [HDF API reference](https://github.com/gpt-cmdr/ras-commander/blob/main/docs/api/hdf.md) and installed `HdfLandCover`/`HdfInfiltration` docstrings own the current read/write contract. Examples do not establish a generic soil-grid importer or support for every infiltration formulation.

Report a missing acquisition/conversion API as a gap.
