# Mapping workflow evidence

Use these as worked procedures, then resolve installed signatures. Notebook output is retained historical evidence, not a fresh qualification of the user's model.

- [Native mapping engine](https://github.com/gpt-cmdr/ras-commander/blob/main/docs/native-mapping-engine.md) documents capability discovery, dimensional routing, sloping/horizontal surfaces, storage areas, derived quantities, catalog scheduling, and explicit 1D/mixed qualification gates. Read the selected method section before requesting maps. `RasFim.get_capabilities()` distinguishes support from numerical qualification; model scope inspection is a separate check.
- [Horizontal mapping comparison notebook](https://github.com/gpt-cmdr/ras-commander/blob/main/examples/602_rust_horizontal_mapping_comparison.ipynb) stages isolated computed projects and all referenced terrain/projection files, compares Rust and RAS Mapper on identical horizontal depth/WSE profiles, then repeats strict pixel-depth filters. Its early wheel/version and future-sloping prose are historical; use current discovery for availability. Reuse its mask/value and timing attribution pattern, not its old installation pin.
- [Froude and shear timestep notebook](https://github.com/gpt-cmdr/ras-commander/blob/main/examples/963_froude_shear_timestep_maps.ipynb) clones a plan, requests cell velocity and face-shear outputs, computes with verification, chooses midpoint/final times from the actual HDF inventory, and checks georeferencing and finite values. It demonstrates native stored-map prerequisites, not automatic fast-map parity for every derived quantity.
- [Stored-map API](https://github.com/gpt-cmdr/ras-commander/blob/main/docs/api/stored-maps.md) is the native RAS Mapper path for comparison; do not compare horizontal output with sloping output under one parity label.
- [Catalog/performance guidance](https://github.com/gpt-cmdr/ras-commander/blob/main/docs/development/fim-mapping-performance.md) explains throughput and resource choices. Record source model, terrain, profiles, concurrency, and measured phase boundaries with a performance claim.

Fast-map's [canonical README](https://github.com/gpt-cmdr/ras-commander-fast-map) assigns HDF/model preparation and `RasFim` supervision to Commander; the Rust engine maps prepared inputs and does not read model HDF directly. An output polygon/bbox preserves global hydraulic dependencies. Missing corners may require explicit Windows/pythonnet preparation; ordinary native mapping has no hidden Python numerical fallback. Consult the installed feature contract before promising a route.
